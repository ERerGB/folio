# Parallel-text and translated editions

Use this when the reader wants English–Chinese or another multilingual comparison. Establish the translation model before producing the text. Prefer Astra for language-intensive translation when available. If the user specified Astra, use an Astra task or model; if the current task cannot switch, say so and arrange a supported route. Do not silently substitute another model or claim Astra provenance. Otherwise choose a model strong at natural expression. Apply `$practice` when the user explicitly wants iterative copy refinement and it is available.

- Keep the source wording and order intact. Pair each source heading, paragraph, list item, quotation, and caption with its translation in the same reading position, normally original first. Place figures near their source references, and identify text inside images that remains untranslated.
- Translate for clear, natural reading while preserving claims, numbers, names, attribution, emphasis, and uncertainty. Check ambiguous terms against the surrounding article. Mark an unresolved ambiguity instead of inventing a fact.
- Validate alignment against the captured source: count content units, compare the opening and ending, check section order, quotations, links, and figure positions, and inspect a narrow reader-sized preview for wrapping and language-specific glyphs. Set language metadata and element-level language tags where the EPUB builder supports them.
- Preserve the original edition and delivery history. Revise a pending edition if it has never been delivered; after verified delivery, create the next numbered edition. Record the translation model and revision reason in private provenance without placing source text or personal book objects in the skill repository.
